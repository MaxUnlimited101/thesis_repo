## Abstract
In the present day, an increasing number of researchers, businesses, and educators seek to incorporate Convolutional Neural Networks (CNNs) into their workflows to enhance productivity. This project aims to improve the quality of classroom communication within an educational context. The developed application allows users to provide and receive emotional feedback, while also offering capabilities to train custom models and upload proprietary versions of datasets. Currently, the emotion-tracking market lacks readily available solutions directly comparable to this project, primarily due to privacy concerns and the prevalence of simpler, non-CNN-based alternatives. This paper addresses these privacy issues, utilizing existing solutions as a benchmark to create a more accurate and refined application. The core functionality enables lecturers to receive real-time, anonymous data on students' emotional states via automated facial emotion recognition. To preserve privacy, facial images are analyzed and immediately deleted, ensuring that instructors view aggregated emotional trends without identifying individual students. This project contributes to both industry and academia. The research describes the model development process, including architectural search for optimal validation accuracy, and the implementation of a user-friendly, easily installable GUI application. To ensure reproducibility and credibility, the project utilizes publicly available datasets, such as AffectNet, alongside standard Python libraries, including PyTorch and TensorFlow. The scripts and frameworks used are accessible online, allowing other researchers to replicate the results efficiently.
